# 应届生学习问答 Agent

一个面向刚毕业应届生的学习问答智能体，帮助用户获得清晰、可执行的 AI Agent 学习建议。

## 能力说明

- 围绕 AI Agent 学习方向进行问答
- 提供由浅入深的学习建议
- 以知识检索与上下文组织为核心思路
- 适合作为基础 RAG 问答实践展示

## 技术思路

项目以 LangChain + FAISS 的知识库检索问答思路为基础，重点验证文档召回、上下文组织和问答效果。
