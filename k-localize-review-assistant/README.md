# K-Localize 本地化审校助手

一个用于审核和优化本地化文案的智能体，帮助发现表达生硬、语境不符、隐私风险及夸大宣传等问题。

## 能力说明

- 审核文案的自然度、准确性与可读性
- 识别术语不统一与场景不匹配问题
- 对存在隐私或夸大宣传风险的内容给出修改建议
- 输出更符合目标用户阅读习惯的优化方向

## 演示场景

- 正常合规文案：展示基础的审校与优化建议能力
- 风险文案：展示对隐私和夸大宣传风险的识别与处理能力
